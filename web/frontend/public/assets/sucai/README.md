# Sucai panel textures

Source: `web/frontend/sucai.png`

The source labels are used only for naming. Each output image keeps only the panel artwork and excludes the green background and label text.

## Files

- `01_main_view_background.png`: main view large background
- `02_card_panel_texture_common.png`: common card panel texture
- `03_info_panel_left_texture.png`: left info panel texture
- `04_info_panel_right_texture.png`: right info panel texture
- `05_small_module_card_texture.png`: small module card texture
- `06_step_module_texture_01.png`: step or feature module texture 01
- `07_step_module_texture_02.png`: step or feature module texture 02
- `08_step_module_texture_03.png`: step or feature module texture 03
- `09_resource_treasure_module_texture.png`: resource or treasure module texture
- `10_world_boss_module_texture.png`: world boss module texture

## Notes

- Filenames are ASCII for stable frontend paths.
- Green-screen edge pixels were checked after slicing and removed by a 2px inward crop.
