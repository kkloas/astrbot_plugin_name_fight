# Web 水墨特效创作参考

## 已确认的视觉方向

- 以淡墨、虚实和飞白表现武侠招式, 避免规则实心尖锥、均匀粗弧和贯穿全程的高亮线条。
- 灰黑墨色为主, 门派色少量点缀。笔触应允许背景透出, 轮廓和浓淡不必完全均匀。
- 用户已认可赤霄断魂刀的第一版素材混合效果。它是后续创作参考, 不是所有招式都应使用同一张图。

## 素材和程序的分工

- 图像素材提供干笔纤维、飞白、墨点和渗化质感; 素材应有透明背景, 保留足够留白。
- Canvas 根据招式时间、方向和位置组织笔触的出现、推进和消散, 并保留必要的程序化细线、粒子和动作连接。
- 笔触的运动应与实际挥击、兵器位置及地面联系起来。静态图整张移动或缩放也可能显得僵硬, 需要在实际播放中判断。
- 素材未加载或不可用时保留程序绘制回退。当前试验素材仅用于 Web 增强特效。

## 已做的试验

- 弧形斩击使用 `assets/ink-crescent.png`, 灰黑飞白中带少量朱砂, 随动作淡入淡出。当前用于赤霄断魂刀的部分基础斩击。
- 赤练裂地使用 `assets/ink-fissure.png`, 裂墨沿地面逐步显现, 与程序绘制的裂痕和烟尘叠加。
- 两张素材由内置图像生成工具创建。具体接入在 `wuxiaMasterArts.js`; 招式可在 `/motion-preview.html` 逐招查看。
- 玄墨剑典尚未接入这些图像素材。后续如扩展, 应针对冷灰和剑势制作合适素材, 避免直接沿用朱砂刀痕。

## 人物动作设计

- 骨骼动画可以表达不同剑路。区分招式时, 应同时考虑脚步、重心、躯干、持剑手和收剑节奏, 不只改变武器角度。
- 玄墨剑典的试验中, 起笔问墨强调低身上挑, 残月掠影强调错步挥斩, 墨影穿云保留突刺作为对照。
- 侧面二维人物对转身透视和正背面变化有局限。先通过清晰的全身轮廓和动作节奏提高辨识度, 有需要时再考虑补充其他素材。
- 人物主动作采用共享骨骼逻辑, Web 与 Bot 都会体现对应姿态变化; Web 增强残影则只在 Web 特效画面显示。

## 多姿态残影与连斩

- 泼墨回风和狂煞乱舞各保留一个清晰的主挥击, 用残影和笔触表达速度与连斩, 避免人物反复来回摆动。
- 残影可以是独立的低斩、上挑、横斩或下劈姿势, 不必只复制人物先前的运动轨迹。不同姿态错时出现在人物附近, 暗示瞬间完成多个动作。
- 强调多个残影同时出现的画面: 让姿态有足够的重叠停留时间, 再缓慢消散, 确保正常速度下也能看清。当前每个姿态的显现和消散合计约 500ms。
- 参考拆解台中泼墨回风约 1099ms 和狂煞乱舞约 1128ms 的画面, 结合完整播放判断效果。残影是视觉表现, 不产生额外攻击或伤害事件。

## 后续验收

- 同时检查完整速度和慢速, 以及左右出招、命中和闪避; 确认笔触方向、出现时机及消散不遮挡人物。
- 检查不同画境下的可读性。浅墨不能完全消失, 墨点也不应压过主体。
- 保持回放和拖动进度条时可复现; 图像加载状态带来的首次显示差异需要在后续产品化时处理。
- 逐招选择素材和节奏, 不用同一笔触覆盖所有剑法和刀法。视觉叠加不应增加实际战斗事件。
